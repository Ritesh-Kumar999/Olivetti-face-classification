# Olivetti Face Classification — Q1 supporting files

Keep these folders alongside `Q1.ipynb` in your GitHub repository.

- `configs/q1_config.json`: model and masking settings.
- `data/README.md`: instructions for saving the exact split indices.
- `figures/q1c_clean_vs_masked.png`: accuracy comparison plot.
- `results/q1_results.json`: recorded metrics and example predictions.
- `results/q1b_bagging_results.csv`: template for exact per-B bagging results.

**Important:** exact split indices and per-B bagging metrics are not invented here; export them from your existing notebook to ensure reproducibility.
